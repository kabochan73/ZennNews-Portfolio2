# 機能要件

[← 目次に戻る](README.md)

## アカウント

| 項目 | 仕様 |
|---|---|
| ログイン情報 | ユーザー名 ＋ パスワード（メールアドレスは使わない） |
| ユーザー名 | 表示名も兼ねる。半角英数字と `_`、3〜20文字。重複不可（大文字・小文字は区別しない。`Takumi` と `takumi` は同じとみなす） |
| パスワード | 8文字以上 |
| 変更 | ユーザー名もパスワードも変更不可 |
| パスワードを忘れた場合 | 復旧手段は用意しない。アカウントを作り直してもらう |
| ログイン状態 | ログアウトするまで保持する |
| 退会 | 確認ダイアログの後、即時に完全削除する（お気に入りタグ・既読・ブックマークも削除） |
| 未ログイン時 | トップページ（紹介）、ログイン、新規登録の画面以外は見られない |

## タグ

- 取り込むタグは管理者（開発者）が Seeder で定義する。ユーザーはその中からお気に入りを選ぶ
- タグの追加・変更はコードを修正してデプロイする（管理画面は作らない）
- タグは約30個。AI タグは入れない。`claude` タグは入れる（`claudecode` は入れない）
- 具体的なタグの一覧と取得時間の割り当ては、実装時に決める

## お気に入りタグの選択

- タグ選択画面では、タグをカテゴリごとに表示し、複数選択できる
- **1つ以上選ばないと保存できない**。0個にはできない
- 新規登録の直後は、タグ選択画面に移動する
- お気に入りタグの数に上限はない
- 並び順は**選んだ順**。一度外して選び直したタグは、一番右（最後）に移動する

## マイフィード

### タグバー

- お気に入りタグを横一列に並べる（横スクロール）
- 選択中のタグは、自動で見える位置までスクロールする
- 右端をフェードさせて、続きがあることを示す
- マイフィードを開いたときは、一番左のタグを表示する
- 常にどれか1つのタグを表示する（全タグをまとめて見る機能はない）
- 切り替えはタップのみ（スワイプでの切り替えはしない）

### タブ

**NEW / READ / BOOKMARK** の3つ。最初は NEW を表示する。各タブに件数を表示する。

| タブ | 表示する記事 | 並び順 |
|---|---|---|
| NEW | そのタグの最新100件のうち、未読の記事（ブックマークしていても表示） | 公開日時が新しい順 |
| READ | そのタグの最新100件のうち、既読の記事（ブックマークしていても表示） | 公開日時が新しい順 |
| BOOKMARK | ブックマークした記事すべて（表示中のタグに関係なく全件。100件の枠から押し出された記事も含む） | ブックマークした日時が新しい順 |

- NEW ＋ READ ＝ そのタグの保持件数（最大100件）
- BOOKMARK はどのタグを選んでいても同じ内容・同じ件数になる
- ページネーションはない（全件を一度に表示する）

### 記事カード

- 表示する項目：絵文字（サムネイルの代わり）、タイトル、著者（アイコン・名前）、公開日時、ブックマークボタン
- タグは表示しない
- タップすると Zenn の記事ページを開く（アプリ内で本文は表示しない）
- 細かいレイアウトは [画面](04-screens.md) を参照

## 既読

- 記事をタップして開いたら既読にする
- 既読は記事ごとに管理する。複数のタグに属する記事は、どのタグで読んでも既読になる
- 既読を未読に戻す機能はない
- 「すべて既読にする」機能はない

## ブックマーク

- NEW / READ のどちらの記事でもブックマークできる
- ブックマークしても、NEW / READ からは消えない
- 上限は1人100件。超えて追加しようとしたら「上限に達しました。いくつか外してください」と表示して止める
- ブックマークした記事は、100件の枠から押し出されても削除しない
- 100件の枠から押し出された記事は、BOOKMARK タブでのみ見られる
