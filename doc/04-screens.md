## 画面一覧

| 画面 | URL | ログイン | 内容 |
|---|---|---|---|
| トップ（紹介） | `/` | 不要 | アプリの紹介と「はじめる」への導線 |
| 新規登録 | `/register` | 不要 | ユーザー名・パスワード |
| ログイン | `/login` | 不要 | ユーザー名・パスワード |
| ホーム（マイフィード） | `/home` | 必要 | タグバー ＋ NEW / READ / BOOKMARK タブ ＋ 記事一覧 |
| タグ設定 | `/home/tags` | 必要 | お気に入りタグの選択。新規登録直後の初回は `/home/tags?welcome=1` |

- 設定画面・ハンバーガーメニューは作らない
- ログアウト・退会は画面に出さない（API のみ用意する）

## 画面遷移

```
トップ ──▶ ログイン ──▶ ホーム
   │                     ▲
   └──▶ 新規登録 ──▶ タグ設定（初回） ──┘

ホーム ⇄ タグ設定（スマホ：画面下のタブ／PC：ヘッダーのリンク）
```

## 共通レイアウト

### ログイン後（`/home` 以下）

- ヘッダー：左にアプリ名、右にユーザー名（長い場合は「…」で省略）
- スマホ（画面幅 1024px 未満）：画面下に **HOME / TAGS** のタブを固定表示する
- PC（画面幅 1024px 以上）：下のタブは出さず、ヘッダーのユーザー名の左に **HOME / TAGS** のリンクを並べる
- 初回のタグ設定（`?welcome=1`）では、下のタブ・ヘッダーのリンクを出さない（タグを選ぶまで先に進めないため）

### 未ログイン（トップ・新規登録・ログイン）

- ヘッダー：左にアプリ名、右に「ログイン」「新規登録」ボタン

### 全画面共通

- フッターに「記事の出典：Zenn」と「本アプリは Zenn 公式とは関係ありません」を明記する
- 配色は白と黒で統一する（アクセントカラーは使わない）

- PC では横スクロールのタグバーの代わりに、左サイドバーにお気に入りタグを縦に並べる（並び順は同じく選んだ順）
- 右側のサイドバーは置かない

#### 仕様

| 項目 | 仕様 |
|---|---|
| バナー | 置かない（バナーはトップページのみ） |
| タグ設定への導線 | タグバー・サイドバーには置かない。下のタブ（スマホ）またはヘッダーのリンク（PC）から行く |
| お気に入りタグが0個の場合 | タグ設定の初回画面（`/home/tags?welcome=1`）へ移動する |
| 記事カード：サムネイル | 絵文字を薄いグレーの四角の中に大きく表示する |
| 記事カード：タイトル | 最大3行。はみ出した分は「…」で省略する |
| 記事カード：著者 | アイコンと名前 |
| 記事カード：公開日時 | 日付と時刻（例：`9/23 14:05`） |
| 記事カード：ブックマーク | 未登録は枠線のみ、登録済みは塗りつぶし |
| 記事カード：タップ時 | Zenn の記事を新しいタブで開き、既読にする |
| 読んだ直後のカード | その場で薄く表示して残す。タブまたはタグを切り替えたときに NEW から消え、件数も更新する |
| BOOKMARK タブ | 既読・未読の見た目の区別はしない |

### タグ設定

```
┌────────────────────────────────┐
│ Zenn News            takumi_k  │
├────────────────────────────────┤
│ 興味のあるタグを選択            │
│ 選択したタグの最新記事を、      │
│ ホームで表示します。            │
│                                │
│ 開発言語             2/10 選択中│
│ [✓TypeScript][PHP][Python][Go] │
│                                │
│ インフラ・クラウド    1/10 選択中│
│ [✓AWS][Docker][Google Cloud]...│
│ ...                            │
├────────────────────────────────┤
│        [  保存する  ]          │ ← 画面下に固定
├────────────────────────────────┤
│    🏠 HOME    │    🏷 TAGS     │ ← 下のタブ（初回は出さない）
└────────────────────────────────┘
```

| 項目 | 仕様 |
|---|---|
| タグの並び | カテゴリごとに表示する（カテゴリ内は `tags.sort_order` 順） |
| 選択数 | カテゴリ名の右に「◯/◯ 選択中」を表示する |
| 見た目 | 選択中：黒地に白文字＋チェックマーク／未選択：白地に枠線 |
| 選択の順番 | タップした順が、そのまま「選んだ順」になる。画面上に順番は表示しない |
| 検索欄 | 置かない（タグは42個で一覧できるため） |
| 保存ボタン | 下のタブの上に固定する。1つも選んでいないときは押せない（グレー表示） |
| 戻るボタン | 置かない（下のタブ・ヘッダーのリンクで移動する） |
| 初回（`?welcome=1`） | 下のタブ・ヘッダーのリンクを出さない。保存するまでほかの画面に移動できない |
| 保存せずに移動 | 確認せずに変更を破棄する |
| 保存後の移動先 | ホームへ移動する |

### トップ（紹介）

デザインの参考：プロジェクト直下の `スクリーンショット 2026-09-25 12.44.43.png`（PC版）。ただし配色・文言・ロゴなどは下記の仕様を優先する。

```
┌──────────────────────────────────────────────┐
│ Zenn News                 [ログイン][新規登録] │ ← ヘッダー（未ログイン時）
├──────────────────────────────────────────────┤
│                                              │
│  Zennを、                                    │ ← ヒーロー（白背景）
│  もっと効率よく追いかける。                   │
│  興味のある技術を登録するだけ。               │
│  最新記事を、自分専用のニュースフィードで。    │
│  [ はじめる → ]  [ ログイン ]                │
│                                              │
├──────────────────────────────────────────────┤
│           このアプリでできること               │ ← 機能（4つのカード）
│  01 タグを選ぶ  02 新しい順で  03 NEW/READ で  04 あとで読む │
│                 チェック      既読管理                     │
├──────────────────────────────────────────────┤
│  Zennとの違い                                 │ ← Zennとの違い
│  × 投稿機能なし        ✓ そのかわり、          │
│  × コメント機能なし      自分が追いたい技術だけを、│
│  × SNS機能なし           効率よく追える。       │
│  × 記事本文の転載なし   「Zenn」→「Zenn News」 │
├──────────────────────────────────────────────┤
│（黒背景）あなたの技術ニュースを今日から始めよう。│ ← 最後の呼びかけ
│              [ はじめる → ]                   │
├──────────────────────────────────────────────┤
│ 記事の出典：Zenn                              │ ← フッター
│ 本アプリは Zenn 公式とは関係ありません          │
└──────────────────────────────────────────────┘
```

| 項目 | 仕様 |
|---|---|
| 配色 | 白と黒で統一する（アプリ全体と同じ）。アクセントカラーの青は使わない |
| ロゴ | 「Zenn News」の文字のみ。Zenn のロゴやそれに似たマークは使わない |
| ヘッダー（未ログイン時） | 左にアプリ名、右に「ログイン」「新規登録」ボタン。「特徴 / 使い方 / よくある質問」のリンクは置かない |
| ヘッダー（ログイン時） | ログイン後の共通ヘッダー（ユーザー名。PC では HOME / TAGS のリンク） |
| ヒーロー | 白背景。見出し「Zennを、もっと効率よく追いかける。」、説明文、「はじめる」「ログイン」ボタン |
| 機能セクション | 「このアプリでできること」として4つのカードを並べる（下表）。スマホでは縦に並べる |
| Zennとの違い | 「投稿・コメント・SNS 機能なし、記事本文の転載なし」と「そのかわり、自分が追いたい技術だけを効率よく追える」を対比する。図の中の Zenn は文字で表す（ロゴは使わない） |
| 最後の呼びかけ | 黒背景（画像は使わない）に「あなたの技術ニュースを今日から始めよう。」と「はじめる」ボタン |
| ボタンの文言 | 「はじめる」（「無料で始める」は使わない）→ 新規登録画面へ |
| よくある質問 | 作らない |
| ログイン済みで開いた場合 | リダイレクトせず、トップページをそのまま表示する（使い方を見返せるように） |

機能セクションのカード：

| # | 見出し | 説明文 |
|---|---|---|
| 01 | タグを選ぶ | Laravel、Next.js、AWS など、自分が追いかけたい技術を登録 |
| 02 | 新しい順でチェック | 登録した技術の Zenn 最新記事を、いつも新しい順で |
| 03 | NEW / READ で既読管理 | 読んだ記事は READ へ。まだ読んでいない記事がひと目で分かる |
| 04 | あとで読む | 気になった記事はブックマーク。最大100件まで保存できる |

### 新規登録・ログイン共通の仕様

| 項目 | 仕様 |
|---|---|
| 入力チェック | React Hook Form ＋ Zod で行い、エラーは各入力欄の下に赤字で表示する |
| 入力のヒント | ユーザー名・パスワードの欄の下に条件（文字種・文字数）を表示する |
| パスワード（確認） | 新規登録のみ。パスワードと一致しない場合はエラーにする |
| パスワードの表示切り替え | 付けない |
| 注意書き | 変更不可・復旧不可の注意書きは表示しない |
| ユーザー名の重複 | 「このユーザー名は既に使われています」と表示する |
| ログイン失敗 | 「ユーザー名またはパスワードが違います」と表示する（どちらが違うかは示さない） |
| ログインの連続失敗 | 「しばらく時間をおいてお試しください」と表示する |
| 新規登録の成功後 | ログインした状態で、タグ選択画面（初回）へ移動する |
| ログインの成功後 | ホームへ移動する |
| ログイン済みで開いた場合 | リダイレクトせず、そのまま表示する |

## 空の状態

| 状況 | 表示する文言 |
|---|---|
| NEW が0件 | 「新着記事はありません」 |
| READ が0件 | 「まだ読んだ記事はありません」 |
| BOOKMARK が0件 | 「ブックマークした記事はありません。🔖 を押すと、ここに保存されます」 |
| タグに記事が1件もない（タグ追加の直後など） | 「記事を準備中です。記事は毎朝3〜8時に更新されます」 |

## 読み込み中・エラー

| 状況 | 動き |
|---|---|
| 記事一覧の読み込み中 | スケルトン（記事カードの形をしたグレーの枠）を表示する |
| 記事一覧の読み込みに失敗 | 「記事を読み込めませんでした」と「再読み込み」ボタンを表示する |
| ブックマークが上限の100件 | トーストで「ブックマークは100件までです。いくつか外してください」と表示する |
| 既読・ブックマークの保存に失敗 | 画面を元の状態に戻し、トーストで「保存に失敗しました」と表示する |
| 未ログインで `/home` 以下を開いた | ログイン画面へ移動する |
| ログインの有効期限切れ・無効 | 「ログインし直してください」と表示し、ログイン画面へ移動する |
| ログイン画面に移動させられた後のログイン | 元の画面には戻らず、常にホームへ移動する |
| 存在しないページ（404） | 「ページが見つかりません」と、トップ／ホームへ戻るボタンだけのシンプルな画面 |
| サーバーエラー（500） | 「エラーが発生しました」と、トップへ戻るボタン |

※ トースト：画面下部に数秒だけ表示され、自動で消える通知。
