# 概要・技術構成

[← 目次に戻る](README.md)

## アプリの目的

Zenn の記事を、自分がお気に入りに登録したタグごとに「最新順」で読めるニュースアプリ。

- ポートフォリオとして提出すると同時に、自分でも日常的に使う
- 自分以外のエンジニアにも使ってもらう（誰でもユーザー登録できる。想定利用者は数人規模）

## コンセプト

Zenn には1日に数百件の記事が投稿されており、すべてを読むことはできない。
このアプリは「全部読む」ためではなく、**自分に関係のあるタグだけを、自分のペースで追う**ためのもの。
NEW はニュースアプリの見出しのように眺め、気になった記事だけを読む・あとで読む、という使い方を想定する。

## アプリの強み（Zenn 本体との違い）

| Zenn 本体の弱点 | このアプリでの解決 |
|---|---|
| お気に入りタグ間の行き来が面倒 | お気に入りタグを横に並べ、ボタン1つで切り替え |
| トピックページがトレンド順で、新着が埋もれる | 常に公開日時が新しい順で表示 |
| 未読と既読が分かりにくい | NEW / READ のタブで明確に分け、件数も表示 |

## スコープ

| 対象 | 内容 |
|---|---|
| 今回作る | タグ別の最新記事表示（ニュース機能）、ユーザー登録・ログイン |
| 今回作らない | Zenn 記事の分析機能、検索、ダークモード、スワイプでのタグ切り替え、メールを使う機能 |

## 技術構成

主要な技術の一覧。ライブラリやバージョンの詳細は [技術スタック詳細](08-tech-stack.md) を参照。

| 領域 | 技術 |
|---|---|
| フロントエンド | Next.js（TypeScript） |
| バックエンド | Laravel（API サーバー） |
| 認証 | Laravel Sanctum（トークン方式） |
| DB | PostgreSQL 17 |
| 開発環境 | Docker（docker compose） |
| 本番環境 | Railway（Dockerfile でデプロイ） |
| 定期実行 | Railway Cron |
| CI/CD | GitHub Actions ＋ Railway の自動デプロイ |
| テスト | Pest / Vitest ＋ React Testing Library / Playwright |
| データ取得元 | Zenn 非公式 API |
